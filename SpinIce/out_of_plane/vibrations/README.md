# 氷則の中を伝わる棒磁石の振動

中央付近の棒を1本だけ軽く弾くと、磁気トルクによって離れた棒も揺れ始める。100本の面外ローターで、刺激した棒から36 cm先に届く波形を計算した。2秒間の全サンプルで、100本の in/out の向きも、三配位52頂点の符号つき磁荷も保たれた。[比較動画（MP4、16秒）](pulse.mp4)・[0.50秒の静止画](preview.png)

## 動画の読み方

丸が弾いた棒、四角が観測する棒。各棒の色は、その棒の N 極の高さが静止時からどれだけ変わったかを表す。赤は上、青は下。左右は同じ色目盛りで、微小変位が見えるようにゼロ付近を拡大している。画面下の波形は四角の棒の変位を線形目盛りで表示する。再生速度はモデル時間の1/8。

- **配置 A** は先の欠陥伝播実験で使った、無外場で氷則を満たす局所エネルギー極小。黄色の六角形では、6本の S → N の矢印が上から見て反時計回りに一周する。[元の配置と極小の検証](../defect_propagation/README.md)
- **配置 B** はその6本を一度だけ反転し、全100本の角度を無外場で再緩和した局所極小。輪の各頂点では「入る1本」と「出る1本」が入れ替わるので、52頂点の磁荷は A とすべて一致する。水平投影の向きが A と異なるのは6本だけで、黄色の矢印はその周回向きを示す。

準備後、どちらも同じ棒（辺43）に N 極が上がる向きの初角速度 0.50 rad/s を与える。他の99本は静止から始め、その後は外場も駆動も加えない。観測点（辺40）は六角形を挟んだ反対側にあり、中心間距離は36 cm。頂点を共有する棒への移動を1段と数えると4段離れている。

## 何が伝わったか

| 観測量 | 配置 A | 配置 B |
|---|---:|---:|
| 観測点で N 極の変位の絶対値が初めて 0.020 mm に達したサンプル | 0.133 s | 0.163 s |
| 観測点の最大変位の絶対値、最初の0.50 s | 0.0723 mm | 0.0398 mm |
| 観測点の最大変位の絶対値、全2.00 s | 0.0758 mm | 0.0752 mm |
| 静止角からの最大角変位、全100本・全時刻 | 0.521° | 0.500° |
| 磁荷が変わった三配位頂点、全時刻 | 0 / 52 | 0 / 52 |

配置 A では、少なくとも1本の端が 0.050 mm 動くまでの時間は、隣の棒で 0.029 s、3段先で 0.108 s、5段先で 0.342 s だった。また 1.767 s には、3段以上離れた棒の運動エネルギーの合計が、最初に与えたエネルギーの30.0%に達した。長距離の磁気相互作用を含むので、閾値を変えると検出時刻も動く。ここで測定したのは局所刺激の広がりと時間波形である。

観測点の最初の揺れには A と B で差があり、2秒全体での最大振幅は近い。つまり、磁荷をすべて読み取っても、それだけでは別の場所を弾いたときの波形を決められない。磁荷を保存するループの向きを、離れた場所の振動から区別できる一例である。実機での変位や減衰は支点の摩擦と慣性にも依存する。

## モデルと再計算

棒の磁極外面間は100 mm、ハニカムの辺長は120 mm。過去の緩和動画と同じ全対の4磁極相互作用を用い、運動方程式は $I\ddot\theta_i=-\partial_i U-I\gamma\dot\theta_i$。慣性モーメントは $5.0\times 10^{-6}$ kg m²、粘性減衰率は $0.20$ s⁻¹で、乾性摩擦は含めていない。両配置の入力は $I\omega_0^2/2=0.625$ µJ。初期エネルギー極小からの変化を追い、N 極の変位を $\Delta z_{N,i}=(L/2)[\sin\theta_i(t)-\sin\theta_i(0)]$ とした。[運動方程式と磁気トルクの実装](../relaxation/simulate.py)

非線形の運動方程式を DOP853 で解き、1/240 s 間隔で481サンプルを保存した。無刺激対照の最大角変化は両配置で $9\times10^{-14}$ rad 未満、力学的エネルギーと粘性散逸熱の収支誤差は入力の $5\times10^{-10}$ 未満だった。各極小の磁気エネルギーのヘッセ行列から独立に求めた減衰固有振動数は、どちらも約0.17–11.6 Hz。固有モードの重ね合わせと非線形計算の角変位との差は、全棒・全時刻の二乗和ノルムで A が7.4%、B が7.6%だった。

この励起の担い手は、支点まわりに面外回転できる棒の集団振動である。関連する正方格子の巨視的人工スピンアイスでも、磁石の機械回転による波の散乱や、磁区壁に局在する振動が数値的に報告されている。[Scafuri ほか、Phys. Rev. Applied 23, 054093 (2025)](https://doi.org/10.1103/PhysRevApplied.23.054093)

[全角度・角速度・符号つき磁荷・固有振動数（NPZ）](response.npz) の第1軸は配置 A、B の順。下記をこのフォルダで実行する。計算には NumPy、SciPy、C コンパイラ、描画には Pillow、Matplotlib、日本語フォント、FFmpeg（または `imageio-ffmpeg`）を使う。

```sh
python3 pulse.py
python3 render_pulse.py
python3 render_pulse.py --still-at 0.5
```
