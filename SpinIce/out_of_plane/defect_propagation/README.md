# 氷則を破った欠陥の伝播

[磁場なしと一定磁場を並べた動画（MP4）](defect-hop.mp4)。金の輪を付けた棒を1本だけ反転させ、手を離した後に**別の棒**が回ることで負の欠陥が隣へ移るかを追った。100本全てを計算し、画面には中央部と、頂点A・Bを結ぶ棒の側面を拡大した。

## 見えた一歩

頂点磁荷 $Q$ は、そこに入る矢印の本数から出る矢印の本数を引いた値とする。氷則は $Q=\pm1$、ここで追う負の欠陥は3本とも外向きの $Q=-3$。Aは頂点24、Bは頂点18、A–Bの距離は120 mmである。

| 一定磁場 1.3 mT でのモデル時刻 | A の磁荷 | B の磁荷 | 棒の動き |
|---|---:|---:|---|
| 解放前 | −1 | −1 | 全52頂点が氷則を満たす |
| 0.000 s | −3 | −1 | Aと頂点30を結ぶ辺35を反転。反対側の頂点30には +3 ができる |
| 0.817 s | −3 | −1 | 揺れの途中でAに再び負の欠陥が現れた後、移動前の両端を最後に判定できた時刻 |
| 0.821〜0.963 s | ? | ? | A–Bの辺27が鉛直を通過する |
| 0.967 s | −1 | −3 | A–B の棒の向きが入れ替わり、Bに負の欠陥が現れる |

解放後にAはいったん氷則に戻り、揺り戻しで再び $-3$ になった。動画では0.800秒と1.000秒の前後を静止表示する。A・Bに接する5本のうち、上表の移動区間で面内射影の符号を変えたのは共有辺27だけだった。Bの $-3$ は約1.05秒で再び未判定になる。この4モデル秒の試行で、明瞭に追えた同符号の氷則違反の移動は1辺だった。

**無外場で同じ辺35を返した対照。** Bで $-3$ が観測されたフレームはゼロだった。一方、正の欠陥を作った頂点30と隣の頂点36では、0.133〜0.267秒に $(+3,-1)\to(+1,+1)$ が起きた。基準配置からの差 $\Delta Q=+2$ は頂点30から36へ移っているが、移動後は両頂点とも氷則を満たしている。この違いを[検出イベント](events.json)の `ice_defect` と `excess_charge` に記録した。

## 初期状態と駆動

- [減衰を弱めた100本の動画](../relaxation/weak-damping/relaxation-100.mp4)の40秒の角度・角速度から無外場でさらに30モデル秒緩和し、同じエネルギーの谷の底を求めた。全52頂点が氷則を満たし、ヘッセ行列の最小固有値は正だった。この局所安定状態の無外場エネルギーは −13.5291 mJ。同じ模型に −13.8666 mJ の氷則配置もあるため、出発配置は大域的な基底状態より高い。[より低エネルギーの氷則配置・全100本の角度](lower-energy-ice.json)
- 磁場ありではこの静止状態から面内方位 −30°（格子の $+x$ 軸基準）の磁場を0.1 mTずつ増やし、各段階で局所最小化した。1.3 mTで全ての三配位頂点の背景磁荷は無外場と一致した。磁場は反転操作の前から固定し、解放後も方向と強度を保った。1.3 mTは一歩を追えた条件の一例である。
- 全ての棒をその場に保持して辺35だけに $\pi$ を加え、時刻ゼロで全棒を角速度ゼロから解放した。操作で与えたポテンシャルエネルギーは、無外場で1.219 mJ、磁場ありで0.949 mJ。手で回す途中の時間は初期条件に含めていない。辺27には外部から個別のトルクを加えていない。
- 4磁極の相互作用、慣性 $I=5\times10^{-6}\,\mathrm{kg\,m^2}$、粘性減衰率 $\gamma=0.2\,\mathrm{s^{-1}}$ は前回と共通。磁場の項は $-\mu\sum_i(\mathbf B\cdot\mathbf e_i)\cos\theta_i$ で、1本のモーメントは両端の磁石の和 $\mu=2q t$。軸に静止摩擦を置かない理想模型であり、実機の磁場閾値と時刻は未校正である。

## 移動の確認方法

共有辺の両端に接する5本について、面内射影の絶対値が全て棒の長さの半分以上になる時刻を探した。前後で両端の磁荷が $(-3,-1)\to(-1,-3)$（正の欠陥なら符号反転）となり、間で共有辺だけが一度反転した場合を一歩として記録した。鉛直に近い棒を含む頂点は「？」とし、その間を補間して欠陥に色を付ける処理はしていない。

毎モデル秒240フレームで記録し、DOP853の相対許容誤差を $2\times10^{-11}$ と $2\times10^{-12}$ にして独立に積分した。両計算で移動前後の時刻は同じフレームとなり、動画の範囲（2.1秒まで）の全頂点の判定も一致した。後半3秒を過ぎると別の棒の角度や判定に差が現れる。4秒の全記録をこの基準で調べると、負の欠陥のA→Bが磁場ありで1件、無外場が0件だった。辺35を返さず静かに解放した対照は、両条件とも4秒間の最大角変位が $2\times10^{-13}$ rad 未満だった。
