# 磁区バトル

**切って、つないで、最後まで残せ。**

Macの共通画面を見ながら、同じWi-FiのiPhone 2台を磁石として操作する二人対戦ゲームです。局所的な磁場で領土を切断・接続し、その後の自然な変化を利用して面積を競います。スマホ1台で遊べる練習モードもあります。

## 起動

Node.js 22以上を使用します。初回はこのフォルダで次を実行します。

```sh
npm ci
npm run build
npm start
```

Macで **http://localhost:3000/host** を開きます。起動中のターミナルは開いたままにしてください。停止は `Ctrl+C` です。

1. MacとiPhoneを、端末間通信ができる同じWi-Fiに接続します。
2. PC右上の **「☰ 参加・設定」** を開き、QRコードをそれぞれのiPhoneで読み取ります。
3. iPhoneを横持ちにします。必要なら画面の回転ロックを解除します。
4. 同じメニュー内で盤面とモードを選び、スマホで「準備完了」を押します。
5. 二人対戦は双方、練習は一人が準備完了すると、3秒後に開始します。

QRコードの「接続先」に複数のIPが表示される場合は、MacのWi-FiのIPを選びます。macOSから受信接続の許可を尋ねられたら、このローカルサーバーの受信を許可してください。ゲストWi-Fiや公共Wi-Fiでは、同じSSIDでも端末間通信が禁止されていることがあります。その場合は端末間通信が可能なネットワークを使用してください。

参加ページはサーバーを起動するたびに変わります。再起動後は新しいQRコードを読み直します。Wi-Fiを変更した場合はPC画面を再読み込みしてください。

スマホの操作が残った場合は右上の「操作解除」で移動と磁場を止められます。指をいったん離して触れ直すと再操作できます。操作画面はピンチ・連続タップ・長押しによる拡大や選択を抑えています。新版を反映するにはスマホ側のページを再読み込みしてください（プレイヤー番号は同じ枠に復帰し、再開は双方の準備完了から）。

PCでは得点・占有率・ゲージ・拠点状況を上部にまとめ、盤面をウィンドウに合わせて拡大表示します。参加・設定メニューは通常閉じており、ボタン、×、Escapeキー、メニュー外のクリックで閉じられます。試合開始のカウントダウンでも自動で閉じます。ルールの補足・描画fpsなどはメニュー内にあります。

## 拠点争奪モード

PCのモード選択で **「拠点争奪」** を選びます。平面版・立体版のどちらでも遊べます。スマホの操作は同じで、二人が準備完了すると開始します。

- **試合は90秒。** 拠点を保持した時間の合計で勝負します。最後の自然緩和時間はありません。
- **固定の3拠点。** AとCは双方の細い橋の先、Bは中央です。このモードは「橋の切断」の盤面を使います。
- **占領するには、円の中の60%以上を自分の色にして、連続1秒維持します。** カーソルを置くだけでは占領できません。
- **保持した1拠点につき毎秒1点。** 2拠点なら毎秒2点。占領までの1秒間は得点になりません。
- **60%未満に崩れると、その場で中立に戻り、得点が止まります。** 奪い返す際にも連続1秒の占領が必要です。
- 3拠点とも中立から開始します。初期状態で自色が多いA/Cも、開始後1秒維持してから占領されます。
- 90秒後に累計得点が多い方が勝利。同点は引き分けで、総面積は勝敗に使いません。

盤面のA/B/Cの旗と円、上部の拠点カードで保持者・円内の色の割合・占領までの残り時間を確認できます。スマホにも両者の得点と拠点状況が出ます。通信断・一時停止中は得点も占領途中のカウントも止まります。

最初は中央Bを取りに行くか、相手側の橋の先を攻めるかを試してください。橋を切っただけでは占領は解除されず、切断後の縮小で拠点内の自色が60%未満になったときに解除されます。

## 別バージョン：立体版

**[立体版を開く](http://localhost:3000/host?view=3d)** ／ **[従来の平面版](http://localhost:3000/host)**

盤面上の「平面版」「立体版」ボタンでも切り替えられます。切替は表示だけで、試合・接続・ゲージは共通です。スマホの操作方法やQRコードはそのまま使えます。

- 青い磁区を高く、オレンジの磁区を低く表示します。磁区の分断・合流に合わせて地形が変わります。
- カーソルの代わりに縦向きの棒磁石を表示します。**P1はS極が下、P2はN極が下**です。赤い半分がN、白い半分がSです。
- 磁場をかけると磁石が少し下がり、作用範囲への光の線が現れます。リングは地形に沿って表示されます。
- 「起伏」で高さの強調、「視点」で見下ろす角度を変えられます。操作方向を保つため、画面の左右・上下は盤面の左右・上下に対応したままです。
- 高さは磁化を見やすくする表示です。計算は従来と同じ二次元モデルで、勝敗も元の面積で判定します。

立体版はPCのWebGLを使います。WebGLが利用できない場合は説明を表示して平面版へ戻ります。3D用のコードは立体版を選んだときだけ読み込み、素材やライブラリはすべてローカル配信します。

## 遊び方

**[立体スピン版を開く](http://localhost:3000/host?view=spins)**：下部の「立体スピン」でも切り替えられます。地形を消し、平らな台に立体矢印を並べます。「本数」スライダーで40〜1296本を調整でき、初期値は144本（16×9）です。密に並べると矢印も小さくなりますが、反転中の長さは一定です。矢印の長さは一定で、磁化が正なら青、負ならオレンジ。表示用磁化が +1 → 0 → −1 と変化すると、上 → 横 → 下に回転します。「視点」で見下ろす角度を調整できます。立体版・立体スピン版では、磁場照射中に青／オレンジの範囲と光の円錐が現れ、「磁場の色」で0〜100%に調整できます。本数と色の強さはブラウザに保存され、再読み込み後も維持されます。これらは表示のみの設定で、磁場の物理的な強さや計算格子は変わりません。連続磁化を間引いて可視化したもので、横向き成分や回転は表示上の演出です。微視的スピンの歳差運動を計算しているわけではありません。

平面版には、青が↑・オレンジが↓の小さなスピン矢印を表示します。磁化が弱くなると矢印が縮み、反転すると逆向きに伸びます。画面サイズに合わせて間引いて表示し、下部の「スピン：ON/OFF」で元の色面表示と比較できます。連続磁化を見やすくする表示で、個々の原子スピンの計算ではありません。立体版は従来の地形表示です。

- **左手：移動。** 左側の好きな位置に触れるとスティックが現れます。その位置を中心に、倒した方向へ磁石が動きます。倒す量で速さを調整できます。離すと停止します。
- **右手：磁場。** 「磁場」を押している間、円の中を徐々に自分の色へ変えます。移動しながら使えます。
- **離す：回復。** 満タンで3秒使用可能。離すと回復し、空から4秒で満タンになります。空のまま押し続けても回復しません。
- 左右交換ボタンで移動と磁場の配置を入れ替えられます。

75秒の操作後、5秒間は磁区の自然な変化を見守ります。80秒後に自分の色の面積が多い方が勝ち。同点は引き分けです。途中で領土がゼロになっても、時間内なら磁場で復活できます。

**橋を切る → 小島が縮む → 道をつないで救う**のが基本です。救援は一点を押し続けるだけでは届かないことがあります。切れた道に沿って、ゆっくり磁石を動かしてみてください。

## 磁化の反転音

PC画面を再読み込みし、上部の **「音をON」** を押すと有効になります。「試聴」で音を確認でき、横のスライダーで音量を調整できます。ONのボタンをもう一度押すと消音します。平面版・立体版の両方で使えます。

磁場を使っている範囲内で色が反転すると、短い金属的な「パチパチ」という音が鳴ります。反転量に応じて強弱が付き、P1/P2で少し音程が異なります。左右の位置も音に反映します。自分の色の上で押し続けても反転がなければ鳴りません。

待機中・一時停止・最後の自然緩和・画面非表示では反転音を止めます。スマホからは音を出しません。音量は保存しますが、再読み込み後はブラウザの自動再生制限に合わせてPCで再びONにしてください。実際の磁性体の録音ではなく、ゲーム用に合成した効果音です。

## 練習・調整・再接続

- PCで「練習」を選ぶと、一人で時間制限なく操作できます。接続している最初のプレイヤーが操作し、もう一人は見学になります。
- 「一時停止」後は、スマホの「準備完了」で再開します。練習では停止中に「盤面リセット」と「調整と設定」が使えます。
- 調整できるのは磁場の半径・強さ、自然緩和の速さ、磁石の最高速度、ゲージの使用・回復時間です。対戦中は一時停止しても変更できません。
- 画面ロック、縦向きへの回転、通信断では試合を一時停止します。同じブラウザで戻ると同じP1/P2に復帰し、双方の準備完了で再開できます。
- 通信が一瞬遅れたときは350msで操作を解除し、1.5秒応答がなければ切断扱いにします。
- PCの画面が非表示になった場合や、PCがスリープ・大きく処理落ちした場合も停止します。再開にはPCの画面を表示してください。
- プレイヤーを交代する場合は、待機画面の「調整と設定」→「接続枠をリセット」を使います。新しい二人がQRコードから参加できます。

設定・戦績はサーバー終了時に消えます。スマホには再接続用の識別情報と左右配置だけ保存します。ゲームはローカル配信で、起動後にクラウドや外部フォントへアクセスしません。

## 開発・確認

```sh
npm run dev           # 開発サーバー。クライアントはViteで更新
npm run check         # TypeScriptの型チェック
npm run build         # 型チェックと配信用ファイルの生成
npm test              # 計算・ルール・通信テスト（先にbuild）
npx playwright install chromium webkit
npm run test:browser  # ブラウザ結合テスト（先にbuild）
```

開発時にサーバー側のコードを変更した場合は `npm run dev` を再起動します。通常起動でコードを変更した場合は再ビルドしてください。別ポートを使う場合は `PORT=3001 npm start` とします。

ブラウザテストは専用ポート3108、通信テストは3109を使用します。これらのポートが空いている状態で実行してください。`test-results/` に画面画像、失敗時のトレースが出ます。
